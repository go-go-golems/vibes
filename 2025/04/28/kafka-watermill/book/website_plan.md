# Website Structure for "Polyglot Event-Driven Systems with Kafka"

## Pages
1. Home/Landing Page
   - Hero section with book title and tagline
   - Brief overview of the book
   - Key features/benefits
   - Call to action (e.g., "Read Sample Chapters")

2. About the Book
   - Detailed description
   - Table of contents
   - Target audience
   - How the book is organized

3. Sample Chapters
   - Preview of selected chapters
   - Code examples

4. Key Concepts
   - Log-centric architecture
   - Polyglot services
   - Event-driven patterns
   - Kafka essentials

5. Technologies
   - Go implementation
   - Kotlin implementation
   - Ruby implementation
   - Kafka configuration

6. Resources
   - Additional reading
   - Related tools
   - Community links

## Design Elements
- Modern, clean interface with code syntax highlighting
- Responsive design for mobile and desktop
- Kafka-themed color scheme (red, black, white)
- Interactive diagrams where possible
- Code snippet showcases

## Technical Requirements
- Next.js framework
- Tailwind CSS for styling
- Syntax highlighting for code blocks
- Responsive navigation
- Fast loading performance
