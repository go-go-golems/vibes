Quick Start Guide

1

Extract & Build

unzip codereview-complete-package.zip
cd codereview/
make build
2

Initialize Repository

cd your-git-repo/
/path/to/codereview init
./codereview create "Review title"
3

Add Annotations

./codereview annotate -f file.js -l 42 \
-t issue -s major "Fix this bug"
./codereview show rev-123456
4

Launch Web Interface

./codereview serve --port 8080
# Open http://localhost:8080
# Enjoy the modern UI!
