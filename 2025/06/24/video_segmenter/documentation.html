🎯 How It Works

Video Upload

Upload your stream video (MP4, AVI, MOV, MKV, WebM) up to 500MB. The system supports various video formats and provides instant video metadata analysis.

AI Analysis

Advanced Gemini AI analyzes each frame using chain-of-thought reasoning, evaluating visual appeal, emotional content, engagement potential, and viral characteristics.

Segment Identification

The system identifies coherent discussion segments and analyzes content flow, narrative structure, and platform optimization opportunities.

Strategic Recommendations

Generates comprehensive strategies including best platforms, posting schedules, content modifications, and performance predictions.

🔌 API Endpoints

POST /api/video/upload

Upload video files for processing and get basic video metadata.

POST /api/video/analyze

Perform AI analysis with quick or full mode options.

POST /api/video/segments

Create video segments and extract keyframes.

GET /api/video/frames/{file_id}/{filename}

Retrieve extracted frame images.

GET /api/video/results/{file_id}

Get complete analysis results for a video.

🚀 Quick Start

Prerequisites

  • Python 3.11+
  • Node.js 20+
  • Google Gemini API key
  • FFmpeg installed

Backend Setup

cd video_segmenter_api source venv/bin/activate pip install -r requirements.txt python src/main.py

Frontend Setup

cd video_segmenter_ui pnpm install pnpm run dev

Environment Variables

# Add your Gemini API key in the frontend interface # or set it as an environment variable GEMINI_API_KEY=your_api_key_here
