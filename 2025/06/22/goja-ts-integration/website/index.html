Overview

This project demonstrates a robust approach to integrating TypeScript with Go using Goja, a pure Go JavaScript interpreter. The integration provides full type-checking, .d.ts generation for Go-native APIs, and a single-binary build that needs no extra runtime dependencies.

With this approach, you can:

  • Write business logic in TypeScript with full type safety
  • Expose Go functions directly to TypeScript
  • Deploy a single binary with no Node.js dependency
  • Enjoy fast development with hot reloading
  • Get proper error reporting with sourcemaps
// TypeScript
function main() {
  try {
    console.log("TypeScript starting...");
    
    // Call Go function
    const user = CreateUser({
      username: "testuser",
      email: "test@example.com"
    });
    
    console.log(`User created: ${user.id}`);
    return { success: true, user };
  } catch (error) {
    console.error("Error:", error);
    return { success: false, error };
  }
}

About

This project was created to demonstrate a robust approach to integrating TypeScript with Go using Goja. It is based on real-world experience and best practices for embedding JavaScript in Go applications.

The key components used in this integration are:

  • Goja - A pure Go JavaScript interpreter
  • goja_nodejs - Node.js compatibility layer for Goja
  • esbuild - An extremely fast JavaScript bundler
  • TypeScript - JavaScript with syntax for types
  • tygo - Generate TypeScript types from Go
  • zerolog - Zero allocation JSON logger
